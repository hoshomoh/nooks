N Nook

A household todo app that looks like a document, not a dashboard. One list primitive, one action to add something, and a printed page that is a real deliverable rather than a fallback. The signature element is the hairline rule under the list title: everything on screen hangs off it, and it is the one mark that survives onto paper.

Words
Actions
Add a member · Add a group · Add a token · Add a list. One verb for creating things, everywhere. Never New, Create, Issue, or Generate.
Sentence case, full stops in prose
Buttons and labels take no full stop. Explanatory lines are sentences and take one. Uppercase is reserved for 11.5px section and column heads.
Say what happens
“Ignore removes the request silently and never notifies the sender.” Not “Are you sure?”. State the consequence in the footer of the thing that causes it.
Never summarise the user
A long note previews as its own first line plus a count of what is left. Nothing is generated on their behalf.
