---
title: Lists and views
description: A nook is a list. Everything else on screen is a way of reading the lists you already have.
---

There is one thing in Nooks and it is a list. No boards, no projects, no folders — a
household todo that needs a hierarchy to maintain has become a second job.

Everything else on screen reads the lists you already have. A view never holds a copy of
an item, which is why ticking something off in Today ticks it off on its list too.

## Making one

**New list** in the sidebar, or `⌘K` and start typing. Name it after the errand rather
than the category: *Saturday shop* is a list somebody finishes, *Shopping* is a list
nobody ever does.

## The views

| View | Shows |
| --- | --- |
| A list | Everything on it, in the order somebody put it in, with what is done collapsed at the foot |
| **Today** | Everything dated today, and everything overdue, from every list you can reach |
| **Upcoming** | The next two weeks, by day |
| **Calendar** | The same dated items by month, for deciding *when* rather than *what next* |

Today gathers what is overdue rather than filing it somewhere else. A list that quietly
hides its own backlog is a list that stops being true.

## Order

Items stay where you put them. Drag to move one, and the order is the list's own — it is
not sorted by date, by who added it, or by anything else Nooks decided was important.
Completed items collapse to the foot behind a count, so a list that has been used all
week is still the length of what is left.

## Pinning

Pin a list and it sits at the top of your sidebar. A pin is yours alone: pinning the
shop list does not move it for everybody else in the house.

## Finding something

`⌘K` searches every list you can reach, across labels and notes both. It is full-text
and it has been there since the first release — not bolted on once somebody had enough
lists for it to matter.
